# v1 — task pipeline (removed)

The v1 task pipeline — `task import`, `spec`, `testspec`, `plan`, `code`,
`verify`, `ship`, `review`, `approve`, `retry`, `job`, `cost`, `trace`,
flows and pattern memory — was removed on 2026-09-28. zforge now works only
through [v1.5](../v1.5/README.md): intake, handover, runs.

These pages describe v1 as it was, for history. None of their commands exist
in the current binary.
